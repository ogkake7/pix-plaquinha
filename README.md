# pix-plaquinha
Transforme pagamentos no balcão! Clientes pagam via NFC em segundos (QR Code/Copia e Cola). Lojistas atualizam a chave Pix num painel dinâmico, sem regravar a tag. Arquitetura serverless veloz e moderna usando Vanilla JS, Vercel Functions e Upstash Redis. O fim dos erros de digitação com máximo desempenho e UX impecável.
